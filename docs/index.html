The result

For every m ≥ 4 and every balanced Boolean function f on n = 2m variables,

nl(f) ≤ 22m−1 − 2m−1 − 4

The classical bound for balanced functions is 22m−1 − 2m−1 − 2. This answers Open Problem 4 of Lou, Xu and Wang (arXiv:2610.17897). The same bound holds for every component of a balanced (2m, r) S-box, and so for permutations of F22m.

In plain words

A Boolean function takes a string of n bits and returns one bit. Ciphers are built from such functions, and a cipher is easier to break when they behave almost like simple linear rules (XORs of input bits). Nonlinearity measures how far a function is from every such rule; higher is better. A function is balanced if it outputs 0 and 1 equally often.

For even n the highest possible nonlinearity is reached only by "bent" functions, which are never balanced. It was known that a balanced function must fall at least 2 below that ceiling. We show it must fall at least 4 below, for every even n from 8 up.

How it is checked

The proof uses only the Walsh transform modulo 16, Parseval's identity and the spectrum of quadratic forms. Every step is checked by the Lean 4 proof assistant, in files that use only Lean's core (no Mathlib), with no sorry and only the standard axioms propext, Classical.choice and Quot.sound. A Challenge/Solution comparator check confirms that the proved statements are exactly these:

theorem even_balanced_nl_le (m : Nat) (hm : 4 ≤ m)
    (F : Vec (2 * m) → Bool) (hbal : isBalanced (2 * m) F) :
    ¬ hasNonlinearityAtLeast (2 * m) F
        ((2 : Int) ^ (2 * m - 1) - (2 : Int) ^ (m - 1) - 3)

To check it yourself, install Lean 4.15.0, clone the repository and run ./verify.sh (about three minutes on a laptop). GitHub Actions runs the same check on every push.
